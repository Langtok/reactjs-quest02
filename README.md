# Welcome to Reactjs Quest02
***

## Task
TIn this quest, we will explore the fundamentals of React.js by creating and modifying components. The challenge is to understand how components work, how to structure them, and how to properly organize a React application while following best practices.

## Description
This project consists of three exercises:

Edit an Existing Component (ex00):

Modify App.js by removing default content and adding new elements.

Customize styles in App.css.

Change the development server port to 8080.

Create a New Component Inline (ex01):

Define a functional component (LoremIpsum) inside App.js.

Use this component inside the main app layout.

Create a New Component in a Separate File (ex02):

Define a class-based component (LoremIpsum) in a new file LoremIpsum.js.

Import and use this component inside App.js.

## Installation
To install and set up the project, run the following commands:
# Navigate to the exercise folder (change 'ex00' to ex01 or ex02 as needed)
$> cd ex00

# Create a new React app
$> npx create-react-app .

# Install dependencies
$> npm install

## Usage
To start the development server, run:

$> npm start

By default, React runs on port 3000, but for this project, we modify package.json to change it to 8080. To start on port 8080, use:

$> PORT=8080 npm start

If you're on Windows, use:

$> set PORT=8080 && npm start

Expected Output

Each exercise should result in a functional React app with the required modifications. Open your browser and visit:

```
http://localhost:8080
```
